1. 结论

价格与预算必须分层。技术价格由税后清算价值、原料机会成本、采购、融资、运输和协调约束决定；图纸预算 B 只判断这一价格向量是否买得起，不能倒推商品“应该值多少”。
  • 配方 DAG 给出一个按拓扑顺序可解、逐分币严格检验的最小整数价格向量。
  • 在固定活跃分支下，连续模型是有限 Leontief 逆；因为依赖矩阵幂零，不存在无穷级数收敛假设。

3. 从一只利己猫逐步推导

  1. 税后清算。目录价为 p 金币时，精确可得 nτ(p)=u·p-ceil(τu·p) 分；连续近似为 u·q·p。
  2. 放弃原料的机会成本。配方 i 消耗 aᵢⱼ 件原料 j，最低应补回 Σ aᵢⱼ nτ(pⱼ)。
  3. 缺料采购摩擦。若按最保守的“全部缺料”条件，共有 mᵢ=Σaᵢⱼ 个订单，决策函数再扣 f·mᵢ。这里 f 是模型参数，不被解释成自然常数。
  4. 逐单融资。每个订单的普通报价是 nτ(pⱼ)+b；零现金时每一单分别产生 φᵣ,ℓ(z)=max(ℓ,ceil(rz))。最低贷款费 ℓ 与最低正利润 ε 含义不同，即使当前都等于 1 分也不能合并。必须逐单求和，不能把总额只取整一次。
  5. 运输与外售二选一。最长 L 跳有至多 L-1 个中转猫，费用上界为 (L-1)h。订单已经多付 b，所以额外所需利润为 M=max(ε,(L-1)h-b+ε)。
  6. 协调项。工作量超过视野 H 时再扣 ρ·max(Wᵢ-H,0)；ρ,H 同样保持可变。

4. 精确整数模型

φᵣ,ℓ(z) = max(ℓ, ceil(rz)) Rᵢ = Σⱼ aᵢⱼ nτ(Pⱼ) + f mᵢ + Σⱼ aᵢⱼ φᵣ,ℓ(nτ(Pⱼ)+b) + ρ max(Wᵢ-H,0) + M Pᵢ = min { p ∈ ℤ₊ : nτ(p) ≥ Rᵢ } M = max(ε,(L-1)h-b+ε)

配方图无环，所以先求六种资源，再逐项求后继。nτ(p) 对 p 单调；因此每一步选出的最小整数都是该前缀的分量最小解。拓扑归纳后得到全向量唯一的分量最小解。

这是“全部原料缺失、零现金、最长路线”的充分价格包络，不是假设每次真实交易都恰好走最坏路线。它保证单笔计划不亏，但不能单独证明有限猫网络会稳定调度。

5. 连续模型与有限 Leontief 逆

一般分段式： pᵢ* = Σⱼ aᵢⱼpⱼ* + [f mᵢ + Σⱼaᵢⱼ max(ℓ,r(uq pⱼ*+b)) + ρ max(Wᵢ-H,0) + M] / (u q) 若每条边都满足 r(uq pⱼ*+b) ≥ ℓ： pᵢ* = (1+r) Σⱼ aᵢⱼpⱼ* + [(f+r b)mᵢ + ρ max(Wᵢ-H,0) + M] / (u q) p* = (I-(1+r)A)⁻¹d = Σₖ₌₀⁶⁴ ((1+r)A)ᵏ d

一般模型是分段仿射。只有比例费率分支全部激活时才使用矩阵化简；按配方拓扑排列后，A 严格下三角，故 A⁶⁵=0。当前代入点该分支为 已验证激活。逆矩阵是有限多项式，不需要凭经验指定“原料统一加价百分比”。

  • ∂S/∂B=0：预算不决定技术价格；预算余量对 B 的导数才是 1。
  • 当前 b<(L-1)h，多 1 分订单溢价既增加少量融资，又减少 1 分运输缺口；后者占优，所以局部导数为负。达到分段边界后符号会改变，不能外推成“订单溢价越大越好”。
  • 税率只对不能同步征税的固定分币成本产生放大；原料与成品都按同一税率清算的比例部分在递推中抵消。

10. 这个证明能证明什么

能证明：给定参数向量后，前 65 项存在可复算的分量最小整数价格，使零现金、全缺料、给定最长路线的单项计划保持严格非亏损，并可检查图纸预算。
不能证明：猫的局部贪心评分会自动产生全网稳态、所有中间品跨窗口持续生产，或 1000 个随机空间种子都通过稳定性验收。那些是容量、路由、信用占用与闭环控制问题，必须继续使用稳态多商品流 LP、对偶瓶颈和确定性三窗口模拟。
