# 猫咪工坊 CatLaw2

法条驱动的自动化制造沙盒。玩家通过自然语言法条影响猫咪共享决策逻辑，在带私人产权、税收、信用、有偿物流和 65 种商品科技树的等距世界中建设工坊。

当前版本：`0.14.17`

## 可靠市场与存档 schema 14

- 猫锁定生产目标前，会对整份配料篮子取得真实供应猫、逐格路线、卖价、中转费和最坏借贷费的可靠报价；任何一项不可达、无法承运或超出累计信用，整份计划都不会建立。
- 买猫不会自行递归制作所有缺少零件。每个供应任务由对应卖猫排队承担，且仍须得到同一份共享法规的真实授权；一只猫可以顺序承诺多件同类商品，但不能同时承诺不同生产线。
- 计划、配料订单、保证金与广播按事务一次提交。递归供应树任一子计划失败时全部回滚，不留下半张订单或冻结资金；同批订单按数字序号稳定结算。
- 法规直接返回 `craft` 时也必须先通过同一套整包融资与非亏损预检。原料未到齐时保留法规归因并等待合同交付，不会绕过市场门槛或凭空获得配料。
- 价格与评分法只影响下一份尚未锁定的计划；已经取得可靠报价的计划和不可撤销运输合同继续按冻结金额履约。系统不再用猜测式上游加价代替真实报价。

## 内存管理（0.14.10）

- Emoji 离屏画布与法规 AST 都使用最多 128 项的 LRU；显示器 DPR 改变时立即清空旧 Emoji 栅格。
- Canvas 以 60 FPS 绘制猫咪移动、工作动作和圆形进度，并继续复用可见猫、场景、排序数组和猫索引，界面选择变化不再重建图片或地面缓存。
- 商品品质色依次使用珍珠白、鼠尾草绿、雾霭蓝、月光紫、香槟金、烟霞红与雾墨黑；均为带高光与明暗层次的低饱和渐变。星门单独使用缓慢流动的粉、蓝、青、金炫彩。猫咪制作、运输商品时，工位顶面、商品光晕和圆形进度环同步使用该商品品质色。
- 法规历史、已关闭报价、广播、审计和短期市场事件均有固定上限；加速模拟会持续清除过期瞬态数据。
- IndexedDB 存档会合并并发写入、跳过无变化状态、写前压缩历史，并保证旧存档不会在重置后覆盖新档。
- 对照基准中，1000 猫运行 60 模拟秒的 RSS 从 270.75 MB 降到 193.43 MB；默认新档推进 3 模拟小时从约 29.1 秒降到 13.5 秒，最终状态与队列结果保持一致。

## Windows 本地直接运行

本地 0.14.17 不做安装器，也不使用单文件自解压。运行：

`release\win-unpacked-0.14.17\猫咪工坊.exe`

必须保留 `win-unpacked-0.14.17` 目录内的 `resources`、`locales` 和 DLL 等邻接文件，不能只复制 EXE。桌面版以 760×720 为 100% 基准，是可在 55%–135% 间整体缩放的无边框置顶桌宠：空白世界保持透明，只留下低透明度等距网格与资源提示；猫咪工位使用完全不透明的灰色实体块。普通模式下左拖与滚轮移动、缩放完整桌宠；点击底栏“地图”后，左拖与滚轮只操作工坊视野，单击相邻地块仍可开疆拓土。右键合法空地并确认新增猫咪后，只创建工位，不切换当前选择，也不自动打开猫咪详情。国库旁提供“一键购买”和“购买并转售”：前者实时显示总成本，后者实时显示有正负号的净额；按钮标题和实时价格分别与国库标签、国库金额使用相同字号。左侧只显示商品生产总值/分与猫咪持币，不显示库存量或活跃猫数量。仓库只显示玩家实际拥有的商品，空品类不再占位。资源中心与地面建筑现在共用严格居中的白底圆形徽章；资源为珍珠白，工厂从鼠尾草绿起步，机床、天线、实验室与反应堆依次升级为雾霭蓝、月光紫、香槟金与烟霞红。猫咪决策气泡最多显示三行，只有第三行仍放不下时才显示省略号。

“设置”中的“猫咪说话频率”可在 0–100% 间调整并随存档保存，默认 70%，0% 会立即清除并关闭决策气泡；频率同时控制逐次触发概率和 0–5 个并发气泡上限，调低后会立即收拢现有气泡，因此每个档位都有可见差异。气泡显示时间由 2.8 秒延长至 4.5 秒。控件大小为 50%–180%，界面文字和猫语气泡分别为 50%–220%，地图为 50%–200%，四项互不联动。旧版共同字体比例会自动迁移到两项字体设置。画布上不再常驻“左键拖动”说明浮窗。

- 桌宠式无边框、置顶、可拖动主窗口
- 桌宠普通模式左键拖动整个原生窗口、滚轮缩放全部控件；“地图”模式把两种输入切换为地图平移与缩放，并保留点击相邻地块开拓
- 右键合法空地只弹出“新增猫咪”按钮；再次左键确认才创建，点击其他位置会取消，空格不再放猫
- 65 种商品通用玩家仓库，只显示实际持有品类
- 点击猫咪逐项收购；猫咪不再自行外部出售
- 一键购买与购买并转售固定在主界面国库旁；仓库抽屉保留库存出售
- 产值/分统计最近一分钟完工商品的生产总值，不使用国库或销售额增速
- 点击桌宠“配方”先打开 65 项图纸购买列表；置顶入口再由系统浏览器打开独立 `recipes.html`
- `recipes.html` 永远保留 65 项一图流；点击商品只高亮直接原料、直接下游与关系线，不切换页面，并在节点内标出当前难度的建筑及曼哈顿距离要求
- 164 条配料线采用独立端口和分离路由：不穿商品节点、不共线重叠，交叉处由白色断口区分，同时约束总线长
- 单项出售、锁定品类、一键卖出全部未锁定库存
- 6 种玩家地标工程与范围叠层加成
- 地标时间减免按剩余时间乘算：两个 `-20%` 依次作用后耗时为 `64%`；动作仍保留最短 2 秒
- 工厂可部署在资源中心周围的空采集格；资源中心本身及其他建筑仍受限制
- 选中猫不再出现黄色工位边框；绿色及以上使用加粗品质边框，蓝/紫只轻抬约 7px，金/红抬约 14px，红色整座工位同步高亮
- `1/2/3/4` 切换 `1x/2x/4x/8x`；`P` 暂停
- 猫咪可原子删除：清算资产、先还贷款、净额进入国库
- 五档累计难度与空间工业建筑
- 难度 5 中第 16–19 项自然完成，第 20 项工厂可用价格突破；第 22–26 项仅靠继续调价会因配料作业、保证金和信用占用形成软瓶颈，需用物流法规疏通
- React + TypeScript + Vite + Canvas 2D
- Electron Windows 桌面版
- Express DeepSeek 法条编译代理
- DeepSeek 为每条法规同时生成 5 句带“喵”的安全台词模板；猫在真实制作或合同运输决策后随机错峰 1–5 秒说话，明确本次动作、对象、预计收益和实际原因
