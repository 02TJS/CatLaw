详情独立侧栏基础价格、图纸状态、制造范围与购买按钮占用独立右栏，流程画布自动适配剩余空间，详情卡不会再遮住商品节点或连线。
图纸仍可购买从桌宠打开时，配方页通过同源页面通道读取国库、制造记录与解锁状态，并把购买请求交回唯一的游戏控制器原子执行。
五项产业认证纸、工具、玻璃、金属、齿轮都实际制造后，线缆至工厂的五项配方才可购买；认证记录结果，不替猫指定生产顺序。
递进基础价值曲线配方图同时显示基础价格和法条修正后的实际售价；早期商品使用合理价格底线，高级商品按科技层级溢价，并保证普通配方成品基础价高于其配料重置价值。
全体共用一个循环所有猫都由同一个共享 for 循环按优先级解释每条 function decide(ctx) 一次；新法加入同一法典，不替换或绕过循环。正在进行的 5 秒动作不被打断。
模型连接可配置“设置”可同时修改 DeepSeek API URL 与密钥；URL 默认 https://api.deepseek.com，也兼容 HTTP(S) OpenAI 接口地址。桌面密钥由系统 safeStorage 加密，既不进入浏览器存档，也不会打进发布包。
每条法规固定三次 DeepSeek 调用第一次生成安全程序和逐函数参数说明，第二次只生成 5 句匹配该法规的猫语，第三次依据最终源码生成完整白话解释。运行时不会再次调用 API。
法规效果只能临时存在价格倍率、固定分币加价、信用、悬赏和候选评分都是当前决策的运行时叠加层，保存在进程内的临时缓存，不写入猫咪、目录、国库、库存、配方或存档。每只猫开始下一次快照时先清除自己的上一轮覆盖；废止、隔离或重排法规时全局缓存立即清空，下一次报价和决策恢复基础规则；已经开始的动作、已融资计划和已成交合同只结算启动时锁定的金额。法规中的“价格+3”按增加 3 金币处理，不会误作 3 倍。
注释与解释不准省略最终源码在每个实际函数第一次出现前显示 DeepSeek 给出的参数意义；草案卡片默认完整展开白话说明，不使用省略号、行数裁切或固定高度滚动框。
可调频率、随机错峰有效制作或有偿运输按玩家设置的 0–100% 频率触发，默认 70%，再按世界种子与决策序号确定性延迟 1–5 秒。同一只猫至少间隔 5 秒；频率还将并发上限映射为 0–5 个。每个气泡最多三行并持续 4.5 秒，可显示在猫上方或下方；除优先避开最高与次高档商品工位外，还会硬避让标题、国库操作、窗口按钮、底栏、滤镜、抽屉、提示和右键菜单。
DeepSeek 自选决策位置生成逻辑可以直接制作、履行合同、使用条件分支或修改候选评分；sell 已从猫咪可执行行为中禁用，生成器会拒绝此类法条。
价格也参与评分价格条例决定实际售价，本地贪心把售价、制作工作量、运输距离和现场需求折成候选基础分。
schema 14 可靠整包报价猫锁定生产目标前，会一次取得整份配料篮子的实名供应猫、逐格路线、卖价、中转费与最坏借贷费。任一配料不可达、承运已满或累计信用不足时，整份计划都不会建立。
真实供应岗位买猫不会沿配方树自行制作所有缺件；每份缺料订单由实际卖猫承担。同一卖猫可按数字订单序号排队制作多件同类商品，但不能同时承诺不同生产线，且每份供应计划仍须由同一份共享法规授权。
事务提交与回滚主计划、子供应计划、订单、保证金和广播一次提交。供应树任一子计划失败便恢复全部长度、序号与冻结资金，不留下半成品市场状态；同批结算按订单数字后缀稳定排序。
直接动作也走市场法规直接返回 craft 时，先执行与 choose() 相同的整包融资和非亏损预检。原料未到齐就保留法规归因并等待合同，不绕过产权、信用、建筑或配方限制。
价格只影响下一计划价格和评分调整只影响尚未锁定的下一份计划；可靠报价和运输合同建立后按冻结金额履约。系统不再用猜测式上游加价代替真实供应报价。
玩家销售回流玩家出售仓库商品时，固定 ×2 收入直接进入国库，用于收购、解锁配方、颁布、废止和地标图纸。
分币与信用一金币等于 100 分，全部内部账目使用整数分。信用额度为当前难度的基础信用加保守净资产；贷款收 2% 且至少 1 分，后续收入优先还债。
不可绕过的利己门槛DeepSeek 可修改制作、合同传递或中间评分，但猫咪 sell、无合同传递、亏损制作和超额信用都会被引擎拒绝。
