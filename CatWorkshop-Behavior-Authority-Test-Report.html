一、共享 behavior 权限验证

悬赏 / 价格 / 税收公开数据→唯一现行 decide(ctx)→合法性与经济门槛→动作命令
  • 0.13.0 中全体猫咪按优先级遍历同一法典；每条法规都是同一种 function decide(ctx) 程序，不替换共享运行时。
  • 悬赏、价格、税、信用、动作与评分均经过同一个法规循环，没有“基础经济”等分类旁路。
  • 只有 behavior 函数显式调用 earnCoins()、choose() 或 weighted() 时，市场规划器才会参与。
  • behavior 返回 null 时，验证得到：零动作、零生产计划、零订单、零合同、零发现、零隐藏物流状态。
  • 每个新动作记录 lawId；每个生产计划记录 createdByBehaviorLawId，并能追溯到当时的共享 behavior 法规。
  • 价格法与税法是被 behavior 读取的经济数据，不能绕过 behavior 直接控制猫咪。
